AI-powered coding assistant for WordPress. Generate code snippets, shortcodes, widgets, and website tools using natural language.

== Description ==

AI Vibe Coder is a powerful WordPress plugin that brings the power of artificial intelligence to your website development workflow. Using natural language processing, you can describe what you need and let AI generate WordPress code for you.

### Features

*   **Code Generator**: Generate WordPress shortcodes, widgets, custom functions, CSS, JavaScript, custom post types, and taxonomies using simple English descriptions.
*   **Content AI**: Create blog posts, pages, and other content with AI assistance. Improve existing content, translate, or summarize.
*   **Snippet Library**: Save, manage, and organize your generated code snippets for future use.
*   **Frontend Interface**: Embed the AI code generator directly on your website for visitors to use.
*   **Multiple AI Providers**: Support for OpenAI (GPT-4, GPT-3.5) and Anthropic (Claude).
*   **Secure & Private**: Your API keys are stored securely and never shared.

### Use Cases

*   **Quick Development**: Generate custom shortcodes and widgets in seconds
*   **Learning Tool**: Learn WordPress development by seeing code examples
*   **Content Creation**: Generate SEO-friendly content for your blog
*   **Code Library**: Build a personal collection of reusable code snippets
*   **Client Projects**: Quickly prototype features for client websites

== Installation ==

1. Upload the `ai-vibe-coder` folder to your `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to AI Vibe Coder > Settings and configure your API key
4. Start generating code!

### Getting an API Key

**For OpenAI:**
1. Go to [OpenAI Platform](https://platform.openai.com)
2. Sign up or log in to your account
3. Navigate to API Keys section
4. Create a new API key
5. Copy the key and paste it in the plugin settings

**For Anthropic:**
1. Go to [Anthropic Console](https://console.anthropic.com)
2. Sign up or log in to your account
3. Navigate to API Keys section
4. Create a new API key
5. Copy the key and paste it in the plugin settings

== Frequently Asked Questions ==

= Is this plugin free to use? =

The plugin itself is free. However, you will need an API key from OpenAI or Anthropic, which may have associated costs depending on your usage.

= Is my API key secure? =

Yes, your API key is stored securely in your WordPress database using WordPress options and is never shared or transmitted to anyone except the AI provider.

= What types of code can I generate? =

You can generate:
*   Shortcodes
*   Widgets
*   Custom Functions
*   CSS Styles
*   JavaScript
*   Custom Post Types
*   Custom Taxonomies

= Can I use this on a live website? =

Yes, the plugin is designed for both development and production environments. The frontend interface can be embedded on any page using the `[ai_vibe_coder]` shortcode.

= Does this work with WordPress multisite? =

Yes, the plugin is fully compatible with WordPress multisite networks.

= Can I save and manage my generated code? =

Yes, all generated code can be saved to the snippets library for later use. You can view, edit, and delete snippets at any time.

= What languages can the AI generate content in? =

The AI can generate content in any language. Just specify your language in the prompt.
