====================================================
  QUICK START GUIDE (5 MINUTES)
====================================================

STEP 1: CREATE ZIP FILE
-----------------------
1. On your computer, select all files inside ai-vibe-coder folder
2. Right-click and select "Send to > Compressed (zipped) folder"
3. Rename the file to "ai-vibe-coder.zip"

STEP 2: UPLOAD TO WORDPRESS
---------------------------
1. Go to your WordPress admin dashboard
2. Navigate to Plugins > Add New
3. Click "Upload Plugin"
4. Choose ai-vibe-coder.zip
5. Click "Install Now"
6. Click "Activate Plugin"

STEP 3: CONFIGURE API KEY
--------------------------
1. Go to AI Vibe Coder > Settings
2. Select provider: "OpenAI (GPT)" or "Anthropic (Claude)"
3. Paste your API key
4. Select model (GPT-4 recommended)
5. Click "Save Settings"
6. Click "Test Connection"

STEP 4: TEST THE PLUGIN
-----------------------
1. Go to AI Vibe Coder > Code Generator
2. Select "Shortcode" type
3. Enter: "Create a button shortcode"
4. Click "Generate Code with AI"
5. Wait for code to appear
6. Click "Save Snippet"

STEP 5: TEST FRONTEND SHORTCODE
--------------------------------
1. Create a new WordPress page
2. Add shortcode block with: [ai_vibe_coder]
3. Publish and view the page
4. Test code generation from frontend

====================================================
  SHORTCODE DOCUMENTATION
====================================================

PRIMARY SHORTCODE: [ai_vibe_coder]
-----------------------------------

This shortcode embeds the complete AI Code Generator interface on any WordPress page, post, or widget area. Visitors can generate code without accessing the admin dashboard.

BASIC USAGE:
  [ai_vibe_coder]

RESULT: Full generator interface with all code types

PARAMETERS:

  type (optional)
  - Description: Preselect the code type for users
  - Values: shortcode, widget, function, css, javascript, post_type, taxonomy
  - Default: generator
  - Example: [ai_vibe_coder type="css"]

SHORTCODE OUTPUT:
  The shortcode outputs a complete, styled interface including:

  1. Type Selector Buttons
     - Shortcode (default)
     - Widget
     - Function
     - CSS Styles
     - JavaScript
     - Custom Post Type
     - Custom Taxonomy

  2. Prompt Input Area
     - Textarea for describing desired code
     - Placeholder text with examples
     - Auto-expanding height

  3. Generate Button
     - Prominent call-to-action
     - Loading state during generation
     - Disabled state while processing

  4. Example Prompts
     - Quick-start suggestions
     - Clickable pills that fill the prompt
     - Type-specific examples

  5. Code Output Area
     - Syntax-highlighted code display
     - Copy-to-clipboard button
     - Horizontal scrolling for long code

  6. Action Buttons
     - Advanced Editor link
     - Generate Another button

  7. Error Handling
     - Graceful error display
     - Retry functionality
     - Helpful error messages

  8. Toast Notifications
     - Success notifications
     - Error notifications
     - Copy confirmation

FRONTEND EXAMPLE:
-----------------

Create a page with this content:

  [ai_vibe_coder type="css]

  <h2>Generate Custom CSS</h2>
  <p>Use the tool above to create custom CSS for your site.</p>

This creates a CSS-focused generator page with explanatory content.

====================================================
  API CONFIGURATION
====================================================

GETTING AN OPENAI API KEY:
--------------------------

1. Visit https://platform.openai.com
2. Create account or sign in
3. Click profile > API Keys
4. Click "Create new secret key"
5. Copy the key immediately (shown once)
6. Store securely (cannot retrieve later)

GETTING AN ANTHROPIC API KEY:
-----------------------------

1. Visit https://console.anthropic.com
2. Create account or sign in
3. Navigate to API Keys
4. Create a new key
5. Copy and store securely

SETTINGS CONFIGURATION:
-----------------------

Provider Options:
  - OpenAI (GPT-4, GPT-3.5 Turbo)
  - Anthropic (Claude Sonnet 4, Claude Opus 4)

Model Recommendations:
  - GPT-4: Best quality, highest cost
  - GPT-4 Turbo: Good quality, faster, cheaper
  - GPT-3.5 Turbo: Fast, cost-effective
  - Claude Sonnet 4: Balanced performance
  - Claude Opus 4: Highest capability

Temperature Setting:
  - 0.3: Most focused, least creative
  - 0.5: Balanced (recommended for code)
  - 0.7: More creative
  - 0.9: Most creative, least predictable

Max Tokens:
  - Code generation: 1000-2000
  - Content generation: 2000-4000
  - Maximum: 16000

====================================================
  TROUBLESHOOTING QUICK REFERENCE
====================================================

PROBLEM: Plugin doesn't appear after upload
SOLUTION:
  1. Verify ai-vibe-coder folder in /wp-content/plugins/
  2. Check ai-vibe-coder.php is in the folder root
  3. Check WordPress error logs
  4. Re-upload files if corrupted

PROBLEM: Menu items missing
SOLUTION:
  1. Deactivate and reactivate plugin
  2. Check for PHP errors on activation
  3. Verify WordPress version compatibility

PROBLEM: API connection fails
SOLUTION:
  1. Verify API key copied correctly (no spaces)
  2. Check account has credits/usage available
  3. Try different browser (cache issues)
  4. Contact hosting about outbound HTTPS

PROBLEM: Generate button does nothing
SOLUTION:
  1. Open browser developer console (F12)
  2. Check for JavaScript errors
  3. Verify nonce is working
  4. Check WordPress AJAX endpoint

PROBLEM: Code output is empty
SOLUTION:
  1. Check API response in network tab
  2. Verify model is selected
  3. Check temperature setting
  4. Try different prompt

PROBLEM: White screen of death
SOLUTION:
  1. Enable WP_DEBUG in wp-config.php
  2. Check debug.log for errors
  3. Increase PHP memory limit
  4. Deactivate conflicting plugins

PROBLEM: Shortcode doesn't display
SOLUTION:
  1. Verify exact shortcode: [ai_vibe_coder]
  2. Check if shortcode is being filtered
  3. Try in a plain page (no page builder)
  4. Verify template file exists
