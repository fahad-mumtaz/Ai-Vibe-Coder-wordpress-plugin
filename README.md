# AI Vibe Coder

AI-powered coding assistant for WordPress. Generate code snippets, shortcodes, widgets, and website tools using natural language, with an OpenAI or Anthropic API key supplied by the site owner.

## Features

- Code Generator: generate WordPress shortcodes, widgets, custom functions, CSS, JavaScript, custom post types, and taxonomies from descriptions.
- Content AI: create and improve blog posts and pages with AI assistance.
- Snippet Library: save, manage, and organize generated code snippets.
- Frontend Interface: embed the generator on a page with the `[ai_vibe_coder]` shortcode.
- Multiple AI providers: OpenAI and Anthropic, configured in Settings.

## Installation

1. Upload the `ai-vibe-coder` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to AI Vibe Coder > Settings and add your own API key.
4. Start generating code.

The plugin itself is free to use. API usage with OpenAI or Anthropic may have costs depending on your usage and API plan.
